# Velin 需求覆盖矩阵

更新日期：2026-08-12

## 已实现

- P0 登录、用户隔离、设备撤销、失败锁定、强制改密和管理员密码策略。
- P0 主机 CRUD、分组/标签搜索、收藏、最近状态、快速连接、高级 SSH 参数和连接测试。
- P1 主机列表/紧凑表格、原子批量分组/标签/收藏/删除及活动会话保护。
- P0 密码/私钥加密凭据、临时凭据、主机指纹首次确认和变更阻断。
- P0 tmux 独立 socket、精确会话恢复/终止、输出缓冲、历史截断提示和工作区版本持久化。
- P0 多标签常驻连接、递归分屏、拖动比例、最大化、焦点恢复、单写多读和确认式控制转移。
- P1 多工作区创建、切换、重命名、删除，旧布局无损升级和版本化跨设备同步。
- P0 终端复制、粘贴保护、搜索、链接、滚动条、下载、OSC 标题、视觉/声音响铃和服务端同步外观。
- P1 会话状态/主机筛选、持久置顶、受控并发批量恢复、移动端 Ctrl/Alt 扩展键盘。
- P0 SQLite WAL、版本化迁移、完整性校验备份、SHA-256、保留清理、健康检查、请求 ID 和优雅关闭。
- P1 OpenSSH config 预览导入、未知字段警告、脱敏 JSON 导出。
- P1 个人命令片段、变量填充、插入/执行分离和高风险执行确认。
- P1 命令片段多终端目标选择、持续目标清单和二次确认。
- P1 TOTP 双因素认证、加密密钥、一次性恢复码、设备设置和关闭复验。
- P1 站内响铃通知、30 秒任务静默关注、通知定位和用户主动授权的浏览器通知。
- P1 SFTP 浏览、排序、隐藏文件、流式上传/下载、新建目录、重命名、确认删除、符号链接和根路径保护。
- P1 本地、远程和动态 SOCKS5 转发；独立监听生命周期，固定环回地址。
- 通过已保存凭据的 SSH 主机访问内网 Web：SQLite 持久配置、左侧资源列表和双击新标签；支持带登录鉴权的路径代理，以及独立监听、根路径直通的主机端口模式；支持 HTTP/HTTPS、上游 Host、WebSocket、重定向与 Cookie，路径模式包含常见 HTML/CSS 和浏览器网络 API 的根路径适配。
- 管理员运行统计：活动用户、SSH 会话、WebSocket、请求、数据库、审计、备份和运行时间。
- 专项自动化：TOTP、OpenSSH、SFTP 路径、转发参数、主机批量事务和跨用户归属。

## 需部署环境验收

- SSH 密码/加密私钥、主机密钥变更、tmux 创建/恢复/精确终止。
- Go 服务和浏览器关闭期间的远程任务连续性，以及 alternate-screen 程序恢复。
- 两个真实浏览器间的控制权确认转移和全局终止同步。
- 不同 OpenSSH/tmux/SFTP 服务端版本和大文件传输。
- 三类端口转发的真实网络流量、远端监听策略和吞吐指标。
- TOTP 与主流验证器应用的扫码/手工录入兼容性。
- 50 用户/200 会话容量基线与高速持续输出压测。

## 明确延期或需要外部基础设施

- 跳板机链、HTTP/SOCKS 上游代理、键盘交互认证和 SSH Agent 转发。
- OIDC/OAuth、LDAP 和细粒度团队 RBAC。
- 多实例高可用、外部数据库/消息总线、PWA 离线壳层。
- 团队共享命令片段、协作输入、审批、Webhook 白名单与签名。
- SFTP 断点续传、在线文本预览、chmod 和浏览器端拖拽队列。
- SFTP 传输队列、精确速度/剩余时间、取消和自动重试；转发断线自动重连。
- 管理员会话配额/自动清理策略、恢复写入维护模式和容量压测。
- 完整终端录制、合规留存和远程主机重启后的任务恢复。
